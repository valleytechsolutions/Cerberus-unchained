02 / SD CARD

Set up your SD card.

Add vendor names, the optional portal page, help and sample scripts. Firmware flashing updates the chips; these files are copied to your card separately.

Download SD assets ↓REV144 ASSET PACK · 1.1 MB ZIPSHA-256 checksum ↓
  1. 01—

    Download and extract.

    Save the ZIP to your computer and extract it. Inside is a folder named CERBERUS.

  2. 02—

    Copy to the card.

    Power Cerberus off and use a card reader with a FAT32 microSD card. Back up an existing card, then copy the CERBERUS folder to its top level. Merge with an existing folder, keeping your logs, recordings and custom files.

  3. 03—

    Eject, insert and start.

    Safely eject the card from your computer. Insert it while Cerberus is powered off, then turn the device on.

CHECK THE FOLDER LOCATION

SD card / CERBERUS / RECON.DB

Copy the extracted folder itself, so you don’t end up with CERBERUS/CERBERUS.

Boot and basic scanning work without this pack. The assets are unchanged from rev136 and compatible with rev144. Recordings and saved maps are created by the firmware on the card.

Already using Cerberus USB SD mode?

After installing the firmware, you can copy the extracted files through its USB SD drive instead of using a card reader. Eject that drive in your computer, then select RETURN SD TO FIRMWARE on Cerberus before using SD features.

Set up manual Wardriving uploads

Download the empty upload profile ↓. Fill in your home Wi-Fi and the service keys you want to use, then save it as CERBERUS/CONFIG/UPLOAD.JSON on the SD card. On Cerberus, open LOGS / UPLOAD → HOME WI-FI / API SETUP → IMPORT JSON FROM SD. Keep your completed profile private. Importing settings does not start an upload. Setup guide and service limits ↗

04 / FIELD GUIDE

Before you connect.

A LITTLE PREP GOES A LONG WAY
01—

Bring the right board.

Production Cerberus with an ESP32-S3, 16 MB flash, 2 MB PSRAM and onboard C5. No expansion board is required. Images are checked against the selected processor before writing.

02—

Give it a few minutes.

The guided flow installs a temporary bridge, the C5 radio, then the S3 application. Select the same board when USB reconnects. The radio step takes several minutes.

03—

Keep your session yours.

USB diagnostics, board identifiers and progress stay in your browser unless you save a report. Reports include board MAC addresses. The installer does not upload board reports or radio captures.
